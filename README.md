# EduFeed - Sistema de Feedback para Professores e Alunos

EduFeed é uma plataforma desenvolvida para melhorar a comunicação e o aprendizado entre professores e alunos. Através de um sistema de feedback bidirecional, o EduFeed oferece um espaço seguro e eficiente para avaliações, sugestões e reflexões que visam aprimorar o ensino e o desempenho acadêmico.

---

## 🎯 Funcionalidades Principais
- **Feedback bidirecional**: Professores e alunos podem enviar e receber feedback de forma clara e construtiva.
- **Avaliações e comentários**: Inclui uma escala de avaliação e espaço para comentários detalhados.
- **Relatórios e análises**: Gráficos e métricas para acompanhar a evolução e as tendências de feedback.
- **Opção anônima ou identificada**: Usuários podem optar por enviar feedback anonimamente.
- **Notificações em tempo real**: Alertas automáticos para feedbacks recebidos.

---

## 🛠️ Tecnologias Utilizadas
- **Frontend**: 
  - HTML5 e CSS3
  - JavaScript para interatividade
- **Backend**:
  - Python com Django
  - Pytz para gerenciamento de fusos horários
- **Banco de Dados**:
  - MySQL e SQLite3
- **Outras Ferramentas**:
  - Bootstrap para estilização (opcional)
  - Gráficos interativos com Chart.js
